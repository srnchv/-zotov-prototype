# Зотов. Архив — публичная часть (Next.js)

Современный фронт поверх API стенда. Живёт отдельно от клик-прототипа (GitHub Pages) — прототип продолжает работать как есть.

## Что внутри
- `app/page.tsx` — главная: АРХИВ со скролл-хореографией из HTML-вёрстки, темы, проекты центра, хронограф, личности (мозаика), карта, коллекции, «Об архиве», футер. Данные — `GET /api/export`.
- `app/m/[id]/page.tsx` — страница сущности по единому шаблону (материал / личность / событие / место / проект / коллекция / организация): метабокс по типу, описание, документы (S3, подписанные ссылки), источники, связанные по группам, «Похожее». Данные — `GET /api/entities/:id`. Счётчик просмотров и хиты посещаемости — как в прототипе.
- `lib/api.ts` — единственное место, где фронт знает про API.
- Разделы, которых здесь ещё нет (поиск, каталоги, хронограф, карта), временно ведут в прототип.

## Локально
```
npm i && NEXT_PUBLIC_API_URL=https://srnchv-zotov-prototype-27ea.twc1.net/api npm run dev
```

## Деплой (Timeweb App Platform)
Новое приложение → Docker → тот же репозиторий, подпапка `frontend/`, порт 3000. Переменная `NEXT_PUBLIC_API_URL` — адрес API (по умолчанию стенд).
